# Attender Dashboard

The Attender Dashboard is the primary interface for exam candidates. It provides a personalized, AI-driven experience focused on exam preparation, performance tracking, and skill development.

## 🚀 Key Features

- **Upcoming Exams**: A prioritized list of scheduled assessments with a "Quick Start" workflow.
- **Completed Exams History**: Comprehensive history of past attempts, including scores and detailed AI-generated feedback.
- **AI Insights & Analysis**: Uses machine learning to analyze performance across multiple exams, identifying strengths and areas for improvement.
- **Practice Zone**: An adaptive learning environment where candidates can solve AI-curated challenges tailored to their skill level.
- **Ghost Mode**: A competitive/stealth feature (located in `GhostModeCard`) designed to enhance engagement and performance.
- **Skill Metrics**: Real-time tracking of Global Rank, Skill Rating, and Streaks.

## 🛠 Technical Architecture

- **Authentication**: Integrated with **Azure MSAL** for secure enterprise-grade sign-on.
- **Data Fetching**: Powered by **SWR** for efficient caching, revalidation, and optimistic UI updates.
- **Animations**: Utilizes **GSAP (GreenSock)** for high-performance, premium UI transitions and staggered entries.
- **Component Stack**: Built using **shadcn/ui** primitives and **Lucide React** icons.

## 📂 Directory Structure

- `page.tsx`: Main dashboard layout and state orchestration.
- `exam-results/`: Detail view for individual exam performances.
- `learning-plans/`: Personalized pathways generated by AI.
- `practice/`: Directory containing the practice zone logic.

## 🤝 Collaborator Notes

- **Data Syncing**: The "Sync Data" button triggers a force-refresh of AI insights via `/api/attender/cache/user-insights`.
- **Modals**: Important modals (Strategy, Requirements, Insights) are lazily rendered to optimize initial load time.
- **Styling**: Uses a consistent "Glassmorphism" aesthetic defined in `index.css`.
